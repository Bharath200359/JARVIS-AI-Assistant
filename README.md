# JARVIS AI Assistant

An offline-first Windows desktop assistant built with Python and Ollama. The goal is to keep core assistant workflows local where practical and make automation easier to customize.

> **Project status:** Personal/experimental project. Review the current code and setup instructions before using it for important tasks. No hosted service or guaranteed production support is included.

## What this project is for
- A learning base for local AI and desktop automation
- A customizable starting point for personal workflows
- A portfolio project demonstrating Python, local models, and automation

## Requirements
- Windows PC
- Python (use the version supported by the current project files)
- [Ollama](https://ollama.com/) and a compatible model
- Any additional packages listed in the project requirements

## Getting started
1. Clone or download this repository.
2. Review the project files and install the dependencies listed in the repository.
3. Install Ollama and download a model compatible with your machine.
4. Configure the project locally and test each feature before enabling automation.

Exact commands and supported features will be documented as the project is tested. Do not assume every feature is production-ready.

## Safety and privacy
- Test commands in a safe environment before using them on important files.
- Keep credentials in local environment variables or a secrets manager; never commit them.
- Review any automation before allowing it to send messages, delete files, publish content, or spend money.
- Local model output can be inaccurate. Verify results.
